# E3 跨会话记忆收益协议

## 本轮范围

本轮包含合成开发集的本地工程矩阵，以及单独获授权的一条 DeepSeek Flash 试采样。完整真实模型开发评测和独立持出评测是后续验收项。

本地矩阵含 30 条任务链。Coding 10 条、Research 8 条、Data 6 条、跨领域 6 条。每条链使用三个环境种子、四个检索组及三个独立会话，合计 1,080 个会话。运行器按冻结的种子打乱任务链和同链各组的执行次序。环境种子控制合成数据和执行顺序。

| 组 | 记忆 | 检索 |
| --- | --- | --- |
| A | 关闭 | 无 |
| B | 开启 | BM25 |
| C | 开启 | BM25 和本地 spaCy 向量 |
| D | 开启 | 混合检索和 E1 冻结的 Pairwise 重排 |

## 会话和验证

同一任务链与环境种子的四组使用相同的合成数据、目标、可选动作和每会话两轮上限。每组拥有独立的 PostgreSQL 项目范围和工件目录，三个会话各用独立的 Thread、Ticket 和 Run。

1. 第一会话读取对应版本的固定来源，交付答案、版本和工件 SHA256。判定器重算预期答案。B、C、D 通过现有记忆写入门将核验后的结果和证据登记为该组唯一记忆。
2. 第二会话以相同版本和相同任务开一个空会话。读取到当前版记忆并通过证据校验的组可以直接提交。所有组都可用同一个只读动作重新检查来源。
3. 第三会话切换来源版本及预期答案。旧记忆标为历史记录。提交必须绑定这个新会话已读的来源版本及 SHA256。历史回执另做拒收检查，该负对照计数独立于任务尝试。

任务只读取预设合成清单、观测记录或数据表。每次读取获得真实的本地 CAS 工件和 PostgreSQL 证据行。本地矩阵使用确定性的决策规则。真实试采样中，DeepSeek 的 JSON 回复负责选动作，运行器执行对应本地读取和评分。

每次真实请求都发送同一协议及该会话的合成状态。真实试采样固定在 Coding 任务 `e3-c01` 和环境种子 `42`，比较四组的全部 12 个会话，最多 24 次调用及 US$0.30。显式开启思考，推理强度 `max`。每次发送前落盘预占，随后记录用量回执。供应商用量未知时保留预占并停止后续请求。费用使用无缓存峰时费率计算上界。 [DeepSeek 思考模式](https://api-docs.deepseek.com/guides/thinking_mode/) · [DeepSeek 计价](https://api-docs.deepseek.com/quick_start/pricing/)

## 指标口径

第二、三会话按任务链、环境种子和会话编号与 A 组配对。第一会话用于生成经验，单列成功数，费用计入全局账本。

- 首次提交成功计入 First-pass，允许先完成只读检查。重复检查和更正回复由动作日志单列。最终成功要求在两轮内提交获判定器认可的答案。
- 错误签名包含业务领域、任务、资源、来源版本、动作和错误代码。工具签名包含同样的任务及来源身份和工具动作。同组较早的匹配签名才计为重复。报告重复数量与占同类事件总数的比例。空分母记为 `null`。
- 每成功任务的模型调用、输入 Token、费用包括同组第二、三会话的失败尝试。汇总费用使用供应商真实 Token 与每次调用的保守费率。P50、P95 采用实测会话耗时的最近秩。
- 旧记忆误用率按收到历史记录的会话统计。只要提交旧版本或旧哈希就记一次误用尝试。旧回执的错误接受数同时单列。

工程通过要求会话全部执行、组别和记忆隔离、检索模式匹配、旧回执负对照全部拒收、用量账本完整。本地确定性矩阵还要求每次提交均能完成核验。正式收益需要真实多任务配对样本和独立持出，单条试采样只用于检查运行链路和观察行为。

## 复跑

工作目录是 `v3/`。使用含已锁定本地向量模型依赖的 Python 3.12 环境。模型安装回执由 `config/rag-model-lock.json` 校验，重排权重使用 E1 准备阶段产物。将具有建库权限的 PostgreSQL 连接配置读入环境变量 `MGAR_E3_ADMIN_DATABASE_URL`。运行器仅创建独立临时数据库。

```bash
python scripts/memory_context_e3.py freeze --model-dir "$MODEL_DIR" --weights "$WEIGHTS" --out "$FREEZE"
python scripts/memory_context_e3.py fixture --model-dir "$MODEL_DIR" --weights "$WEIGHTS" \
  --freeze "$FREEZE" --freeze-sha256 "$FREEZE_SHA256" --out "$FIXTURE_DIRECTORY"
```

`pilot` 命令还要求限定合成数据范围的授权文件、与其绑定的离线通过回执以及环境中的 DeepSeek 凭据。授权固定冻结哈希、离线回执哈希和本轮的输出目录。使用新目录或重发模型请求之前，需要先核对历史用量及本轮授权。
