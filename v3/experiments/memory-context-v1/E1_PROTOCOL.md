# E1 正式评测协议

本协议沿用 [E1 准备说明](E1_PREPARATION.md)。源码资料锁定公开提交 4e2fe05，30 个主题共 1,080 条记忆。210 条开发题和 90 条独立持出按主题隔离。各题由先前未接触检索输出的标注方对照固定源码或合成控制事实给出 0–3 的相关等级，3 分代表直接回答。记录答案是否存在、每条正例的来源和选择理由。持出目录由独立评测方操作，公开回执含汇总和哈希。

## 冻结和评分

- 冻结锁定语料、查询、标注、候选源码、权重、嵌入安装收据、依赖和查询时钟。持出须匹配独立方封存的语料、题目、标签哈希及固定配额。
- 导入新建的独立 PostgreSQL，保持全部迁移和触发器。语料 UUID 用作实际 Memory ID，固定创建时间和生命周期。逐条写入 CAS，公开片段带版本和行范围的原生证据行。默认加权路径与准备轮的本地 spaCy 300 维向量和 16 对校准权重一致。
- 只把查询和范围交给运行器。五组共用生产存储授权后的候选，以固定排序版本比较 BM25、Dense、RRF、重排和治理。运行器在授权后按相同文本复用向量，每个拆分独立启动。运行记录保存候选、完整各组排序、版本标记、过滤计数和失败原因。每道题都有记录。
- 评分器在运行结束后接收密封标签。Recall@5/10、Precision@5、MRR@10、nDCG@10 以有答案题为分母，失败项计零。Precision@5 始终除以 5。nDCG 增益为 2 的相关级次幂减 1。无答案误报统计经执行的无答案题有任一 Top-10 返回的比例，失败题单独保留。ACL 统计检索候选和全部返回项。过期或错误 Commit 单独统计 Top-10 暴露，并复核重新验证标记。
- 完整组相对 BM25 的 Recall@5 至少增加 5 个百分点。MRR@10 的配对差取主题聚类 Bootstrap 10,000 次，固定随机种子 20261120，95% 区间下限须大于 0。全部题目需实测，ACL 泄漏和版本标记错误须为 0。两拆分均按同一候选执行并分别评分。总质量门取两拆分均通过。

## 运行入口

使用已安装本地向量的锁定 Python 环境。命令在 `v3` 下运行，先用 `freeze` 生成清单，再用 `run` 生成原始结果，最后用 `grade` 计算指标。`MGAR_E1_ADMIN_DATABASE_URL` 指向获准创建临时库的 PostgreSQL。运行仅创建和回收该次独立数据库。持出、标签、冻结清单及输出保存在仓库外。

```bash
python scripts/memory_context_e1.py freeze --help
PYTHONHASHSEED=0 python scripts/memory_context_e1.py run --help
python scripts/memory_context_e1.py grade --help
```
