# E5 记忆检索性能实验

**执行验收 PASS。** 1,000、10,000、100,000 条记忆的 120 个组合全部完成，主矩阵 120,000/120,000 个请求成功。原生连接与即时向量对照 480/480 成功。60 对冷热结果摘要和 12 个原生对照样本组均一致。运行器耗时 36 分 03 秒，模型 API 调用为 0。 [实验协议](../E5_PROTOCOL.md)

## 吞吐和尾延迟

三个规模、四种算法的 12 个热缓存组合都在 5 并发达到本轮最高吞吐。下表比较同一算法 BM25 + Dense + RRF 在 5 并发时的结果。

| 记忆条数 | QPS | P50 | P95 | P99 |
| ---: | ---: | ---: | ---: | ---: |
| 1,000 | 116.1 | 50.7 ms | 70.9 ms | 88.1 ms |
| 10,000 | 113.8 | 51.0 ms | 73.5 ms | 85.3 ms |
| 100,000 | 69.1 | 53.7 ms | 185.2 ms | 217.6 ms |

100,000 条组的热缓存结果。各格均测 1,000 次请求。

| 算法 | 5 并发 QPS | 5 并发 P95 | 5 并发 P99 |
| --- | ---: | ---: | ---: |
| BM25 | 73.4 | 180.0 ms | 225.8 ms |
| BM25 + Dense 等权融合 | 72.9 | 175.1 ms | 227.7 ms |
| BM25 + Dense + RRF | 69.1 | 185.2 ms | 217.6 ms |
| Hybrid + Reranker | 60.2 | 220.7 ms | 277.2 ms |

100,000 条组的热缓存 RRF 在 1、5、10、25、50 并发时实测吞吐为 45.8、69.1、53.1、51.9、47.8 QPS。5 并发增加至 50 并发时，P99 从 217.6 ms 升至 2,875.2 ms，吞吐下降 30.8%。 [完整冷热对照图](e5-performance-20261120.png)

## 资源和阶段

100,000 条、5 并发、热缓存时，权限过滤与候选加载占四组平均耗时的 91.5%–94.1%。生产加载逻辑会逐条读取候选的类型明细，该阶段还包含应用端反序列化和排队时间。单请求平均 25.94 个候选，最高 64。四组各发生 95,090 次索引回表读取，PG 平均使用 0.28–0.31 个 CPU 核，容器内存采样峰值为 41.5–41.9 MiB。

| 阶段 | RRF 平均耗时 | Hybrid + Reranker 平均耗时 |
| --- | ---: | ---: |
| 权限过滤与候选加载 | 65.273 ms | 74.002 ms |
| 来源查表 | 2.870 ms | 3.301 ms |
| BM25 | 0.757 ms | 0.785 ms |
| Dense | 0.717 ms | 0.757 ms |
| RRF | 0.018 ms | 0.021 ms |
| 重排 | — | 1.288 ms |
| 结果组装与协调 | 0.567 ms | 0.707 ms |
| Embedding 子耗时 | 0.026 ms | 0.051 ms |

所有冷态的目标缓冲页起始为零。冷态随后随请求升温，整格数据库块命中率中位数为 99.79%，各格读取 248–906 个共享缓冲缺失块。热态在 96 次预热后采集，本轮 60 个热态格的数据库块命中率均为 100%。每格另存前 100 个请求的延迟，操作系统页缓存沿用宿主实际状态。

主矩阵使用每线程一个复用的只读连接和预热后的本地向量缓存。100,000 条时的单并发原生对照按次连接并即时计算向量，每算法 40 次。

| 原生对照算法 | QPS | P50 | P95 | P99 |
| --- | ---: | ---: | ---: | ---: |
| BM25 | 21.0 | 40.4 ms | 83.6 ms | 98.9 ms |
| BM25 + Dense 等权融合 | 3.3 | 256.9 ms | 686.7 ms | 738.2 ms |
| BM25 + Dense + RRF | 3.4 | 240.9 ms | 665.7 ms | 689.6 ms |
| Hybrid + Reranker | 1.8 | 447.3 ms | 1,287.5 ms | 1,324.0 ms |

原生 RRF 的平均 Embedding 耗时为 246.0 ms，加重排为 496.7 ms。原生对照同时改变连接和向量缓存，记录的是这两项配置叠加后的单机表现。
