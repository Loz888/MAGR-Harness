**定位。** E 组已包含重排与版本治理。相对 A，E 在开发集的 MRR 从 61.76% 升至 92.63%，持出从 81.68% 升至 87.92%。两个集合的 E 组和 A 组均对全部无答案题返回结果。加上 F 的绝对证据门之后，78 个开发正例和 85 个持出正例被拒。D 重排在持出的 Recall@5 与 A 相同（68.56%），E 也在这一水平。完整方案的泛化失败由实际返回和覆盖率共同反映。

**成本与边界。** 持出上，热文本缓存下 BM25 阶段的中位数为 0.49 ms，Dense 阶段另用 1.97 ms，融合与已训练线性重排另用 1.15 ms，版本与拒答校准另用 0.71 ms。两次正式实测分别耗时 47.70 秒和 34.09 秒，含数据库创建、装载和清理。生产计量与高并发性能需另行实测。开发 BM25 到满分仅有 1.98pp 空间，预先冻结的 5pp 门在这套开发题上不可达到；独立持出仍有提升空间，也未达到门槛。

历史公开 Git 快照经哈希复原 1,080 条记忆，加上两份共 522 条更新，六组共用 1,602 条记忆、生产 SQL 权限过滤、相同候选上限与 Top-10 预算。Dense 使用锁定的真实 spaCy 中文预训练模型，重排使用已有的本地 16 对样本训练权重。两次单次评测均在本地 PostgreSQL 16.12 运行，外部模型请求、供应商 Token 与费用均为 0。开发采用模板化任务，独立方另外编写合成目录材料；统计区间覆盖 21 个开发主题或 6 个持出范围内的群组变化，评价范围限于此次语料。旧私有持出未开启，本轮持出只运行一次。
