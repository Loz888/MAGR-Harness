# Phase 4 E5-R1 查询性能与证据复核 · 2026-11-21

**E5-R1 性能候选 PASS。** 合计 172/172 格、36,864 次本地检索实测。
同格使用相同的只读连接复用、冻结向量模型、BM25 与 RRF。原 E5 的四种排序算法基线已另行复核。新候选仍在实验分支和隔离 PG。付费模型调用和远程写入均为 0。

## 关键性能门

每个优先格 512 次请求，三轮按冻结次序执行。两项各三轮均满足改善门。单格 P50/P95/P99、均值 bootstrap 区间、错误率、数据库 CPU/内存、行扫描、缓存命中及阶段耗时均可从指标复核。[完整指标](metrics.json) · [压缩原始样本](samples.tar.gz)

| --- | ---: | ---: | ---: |
| 原实现 | 52.0 请求/秒 | 2,796.1 ms | 2,710.2 ms |

基线的 256 次剖析请求触发 6,688 次逐条明细 SQL。完整组使用一条查询把权限前置的 Top-N 与明细合并。优先格 5 并发条件下，权限与候选加载的请求 P50 的三轮中位数由 60.64 ms 降到 16.91 ms。PG 行扫描计数由 49,392 增至 59,520 每格。单条 SQL 内部的候选选择计划时间另在 EXPLAIN 中保存。专属连接在计时前取得，采样窗内没有逐请求连接等待。
