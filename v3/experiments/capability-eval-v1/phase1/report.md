## 快照恢复

中断导入后，只有在确认原客户端退出、后端连接已结束且目标数据库为空时，才允许原命令重新导入。恢复旧快照支持显式 `--upgrade`。独立演练中，前向迁移失败后已导入的数据库保留 40 项迁移，运行目录尚未发布。排除 SQL 故障并从 PATH 中移除 pg_restore 后，原命令完成全部 41 项迁移，哈希均与发行版匹配。原 Cookie、CAS 和加密配置的核对均通过。发布权限故障曾产生暂存目录清理告警，恢复原权限后可在相同目标重试。[H18 八门复验](independent/h18-report.md)
