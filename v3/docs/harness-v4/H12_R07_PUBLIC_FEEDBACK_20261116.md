## 修复结果

- 每次成功编辑后由 Harness 主动运行已冻结的静态、目标、公开探针及完整公开回归。
  固定命令 ID 不接受模型替换 argv；额外回归只用原已批准执行器，不扩大文件/网络/
  凭据权限。同批多次编辑分别检查，各自绑定实际树，内部观察保持原工具消息配对。
- Public Test Feedback Contract 给 Worker 真实退出码、失败 ID、断言上下文、数量、
  原始日志 CAS、树/Run/任务语义及原始执行 epoch。当前反馈固定进入 WorkingState，
  压缩历史不能把旧树绿结果替代新补丁；最终摘要也重新校验结果树。
- 模型期完整回归沿用 R05 冻结报告器解析 Python/unittest、Go JSON、Node TAP、Mocha
  JSON，避免 JSON 被旧摘要逻辑当成“无测试”。unittest 在名称和 ERROR 之间插入
  argparse usage/stdout 时保留身份，仍校验唯一测试、数量、终态及退出码。
- 签名排除耗时/UUID/地址等常见噪声。相同树、命令和失败不因新回执或日志 hash
  重置检测；默认连续 3 个无进展批次有界停止。配置和状态冻结并持久化，所有自动
  检查继续消耗原工具预算，超时收紧到剩余时间，恢复不重置原额度。
- 两种真实崩溃点均验证：外层工具已知、或仅进程已知。恢复从原 PG/journal 补回
  缺失观察，已知命令不重派发；反馈来源 epoch 保留原 provenance，不能伪写当前 epoch。
- 公共规格可通过原 ask_user 等待澄清，再在同一 Run/权限/预算继续。最终私有 Judge
  结果不进入 Worker；知道未签发的私有 CAS hash 仍不能读。公开绿不升级为 Agent PASS。
