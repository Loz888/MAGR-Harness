# H17 委派对照与默认启用准则

单 Agent 为默认。真实效果门须在首次模型采样前冻结 12 个配对任务、独立判定器、模型、工具链和初始树。两臂沿用相同的总模型次数、累计 Token、金额与期限。委派臂须比单 Agent 至少多通过两题，保守费用增长不超过 25%，中位耗时增长不超过 20%，并且零新增冲突、越权、重复派发和无主执行，才具备调整默认值的依据。

工程对照先固定两例。每例从相同源码新建隔离工作区，使用受控模型跑单 Agent 和一次仓库专家委派。控制模型使用相同主流程；委派作为独立模型步骤计费和计时。
