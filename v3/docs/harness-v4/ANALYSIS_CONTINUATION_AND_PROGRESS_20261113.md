  关闭，也保留可信终态结算。缺必要事实仍为unknown；模型/价格/预占检查继续执行。
- 新`model_stream_failed`只记录原因、字节/帧数、状态与hash，不保存私有正文。
- 自动分析按当前Run已授权的固定版本CAS服务重复/跨问读取，保留证据ID；损坏、
  scope拒绝或取消不回退联网，也不发布迟到观察。明确缺失才可按原授权重新读取。
- 按实际可见源行覆盖判定进展，重叠范围和新标题不造进展。分页给真实总行数、
  可见范围及具体下一段参数；补齐CAS hash。固定调用的历史手动执行计划仍保留。

  页面公开显示证据复用，不显示私有推理。
